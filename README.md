# Pengaman-wifi-tenda-n301
TENDA N301 SECURITY AI PRO v1.0
Sebenarnya, aplikasi TENDA N301 SECURITY AI PRO v1.0 yang sudah kamu jalankan berfungsi sebagai alat pemeriksaan dan analisis keamanan jaringan WiFi milikmu.
Jadi, bukan sekadar scanner biasa. Ini fungsi setiap menunya.
👇👇👇👇👇👇👇👇👇👇
     [INFO MENU]
1. Router Detector
Mendeteksi alamat IP router, IP HP, dan menguji apakah router merespons.

2. Local Network Scanner
Mencari perangkat di jaringan lokal yang merespons ping. Contohnya HP, laptop, dan perangkat lain.

3. Router Port Audit
Memeriksa port jaringan router yang terbuka atau tertutup.

4. Web Admin Checker
Memeriksa apakah halaman administrasi router dapat diakses melalui HTTP atau HTTPS.

5. Connection Stability Test
Menguji respons router, menghitung rata-rata ping, dan melihat paket yang gagal.

6. WiFi Password Analyzer
Menilai kompleksitas password WiFi secara lokal tanpa mencoba membobolnya. (contoh buat kata sandi yang paling aman) = Rumah!Aman2026#Kuat

7. AI Security Advisor
Memberikan rekomendasi untuk memperkuat keamanan router.

8. Save Security Report
Menyimpan hasil pemeriksaan ke file JSON agar bisa diperiksa kembali. (Laporan akan tersimpan dalam folder): tenda_report/

9. Exit
Keluar dari aplikasi
